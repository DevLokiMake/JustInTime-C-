# Что показали снимки окон (этап 6, 2026-11-14)

Снимки сделаны экраном Automation. Содержимое чатов в репозиторий не включено.

## WhatsApp Desktop (с сайта whatsapp.com, WinUI + WebView2)

- Окно процесса `WhatsApp.Root` (класс `WinUIDesktopWin32WindowClass`) это пустая оболочка: заголовок и один элемент WebView.
  Само содержимое лежит в отдельном окне процесса `msedgewebview2` с заголовком `WhatsApp` (класс `Chrome_WidgetWin_1`).
  Адаптер ищет окно по паре «процесс msedgewebview2 + заголовок WhatsApp + наличие Document с id RootWebArea».
- Дерево доступно полностью (DOM страницы). Нужные элементы:
  - поиск: `Edit` с именем «Поиск или новый чат», шаблон Value;
  - список чатов: `DataGrid` «Список чатов», элементы `DataItem` (имя содержит имя чата, время и последнее сообщение);
  - поле ввода: `Edit` с именем «Введите сообщение в чат '<имя чата>'», шаблон Value. Имя содержит название открытого чата,
    это можно использовать для проверки получателя;
  - заголовок чата: `Button` «Данные контакта <имя>»;
  - кнопка отправки при пустом поле это «Голосовое сообщение». Как выглядит кнопка при введённом тексте, ещё не снято.
- Имена элементов локализованы (русский интерфейс). Адаптер должен учитывать язык интерфейса.
- Открыть оболочку нужно развёрнутой: свёрнутое окно может не отдавать дерево.

## Telegram Desktop (Qt)

- Одно окно, дерево доступно. Заголовок окна содержит имя открытого чата и счётчик, например «Имя – (число)».
- Поле ввода: `Edit`, класс `Ui::InputField` (внутренний `Ui::InputField::Inner`), имя «Сообщение...».
- Кнопка отправки: класс `Ui::SendButton`, при пустом поле имя «Запись голосового сообщения». Вид с текстом не снят.
- Поиск: `Edit` «Поиск»; список чатов: `List` «Чаты», элементы `ListItem`; сообщения: `List` «Сообщения».
- AutomationId бесполезны (длинные составные строки), надёжны имена и классы Qt.
- Официальные ссылки: `tg://resolve?domain=<username>&text=<текст>` и `tg://resolve?phone=<номер без +>&text=<текст>`
  открывают чат и вставляют текст в поле (core.telegram.org/api/links).

## Результаты второго эксперимента (ссылки)

- `whatsapp://send?phone=+...&text=...` открывает нужный чат, поле ввода называется «Введите сообщение в чат '<номер>'»
  (номер с пробелами, для сверки сравниваются только цифры). Но в снимке поле пустое: параметр `text` в этом клиенте
  не вставил текст (или снимок снят без него). Для чата с самим собой заголовок «Данные контакта <номер> (Вы)».
- `tg://resolve?phone=...&text=...` открыл чат «Избранное» (свой номер), но кнопка отправки осталась «Запись голосового
  сообщения», то есть текст в поле тоже не появился. Нужно проверить на чате с другим пользователем или через username.
- Поиск окна по заголовку «Telegram» находит и браузер с вкладкой, где есть слово Telegram. Адаптер должен искать
  окно по имени процесса `Telegram`, а не по заголовку.
- Сообщения Telegram видны как `ListItem` с текстом и «Отправлено в ЧЧ:ММ»: так можно проверять, что сообщение появилось.
